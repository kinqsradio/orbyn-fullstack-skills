## Independent policy changes

- Optional library-root `repo/<target>/` and `repo/<target>-wt/<purpose>/` paths;
  research remains in `orbyn-references/`. Neither enters the public index/export.
- Resolve target Git roots and applicable instructions. Preserve their skills
  in place and add compatible methods without relocating upstream guidance.
- Separate local tooling from upstream adoption. Preserve collisions, use local
  exclusions for newly owned assistance files and inspect the target PR.
- Separate library delivery from each consumer's promotion authority. A held
  product pin remains unchanged when the library advances.

These changes remain a public-library candidate. Orbyn stays on approved public
revision `40d323c`; no new consumer import, repin or integration PR is authorized.
All REA changes remain deferred. Seven disposable Git/install checks cover nested
roots, target-file preservation, shared worktree exclusions, name collisions,
forced gitlinks/reference tracking and managed-export exclusion. They do not
prove live Codex/Claude/Cursor instruction discovery. Evaluation additions are
development definitions; previous cases and frozen holdouts are retained.

## Follow-up improvement candidate

The user requested improvements after this comparison. Existing owners now carry
original additions: an optional versioned continuation record with an offline
consistency checker; selective routing guidance; explicit Cursor project links
and all-host migration preflight; and ownership-aware rollback on ordinary link
registration failures. The checker distinguishes stale revisions, failed versus
unrun checks, task completion and actual delivery. It validates consistency, not
the truth of evidence or authority. Small tasks stay direct.

[Cursor documentation](https://cursor.com/docs/skills) confirms native
`.cursor/skills` and compatibility with `.agents/skills`. No host settings,
user-home configuration, model or provider changes are part of this candidate.
The existing Codex/Claude `both` selector retains its meaning; `all` is explicit.
Runtime discovery is separate from disposable filesystem fixtures. Paired Codex
trial results, when obtained, are recorded separately with exact candidates and
limits. No claim about Claude or an offline model follows from those trials.

No source text, protocol or installer from prompt-me was imported. Existing
upstream attribution and the deferred REA boundary remain unchanged.
