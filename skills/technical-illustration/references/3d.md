# Documented beta 3D support

This path remains **beta**. Use it only when true turning/deformation explains the
mechanism better than core SVG. The maintained `kit/turn.mjs`, turn-build,
turn-audit and related check/fidelity/benchmark tools are the selected workflow.
Experimental turn-fixed, canvas-painter and gl-shared are excluded; their packager
exports reject use. Do not quietly switch implementations to obtain a pass.

## Define the supported envelope

State part/group IDs, parents, world transforms, axis/pivot, valid angles and actual
time schedule. Read the exact TURN/build/audit APIs and required convex decomposition
for the chosen shape. Preserve group references through clipping and generated
pieces. A rendering that looks plausible does not prove convexity, collision
clearance, group identity or meaningful shader masks.

Separate visual grouping from physical attachment. Test hinge/free-clipped parts,
parent motion, tubes/cuts and projection in actual temporal order. A list of angle
samples is not the same path as eased acceleration, reversal or a detached piece.
Do not round coordinates before checking continuity; that can hide a jump.

## Build and check

Start with a small supported model and build the standalone artifact from exact
source. Run the configured turn audit, check and fidelity paths over the full
selected finite bounds, not a quick subset labelled full. Plant missing
decomposition, wrong group/parent and a temporal discontinuity; each must fail at
its actual boundary. Line and surface coverage remain necessary but are not an
independent proof that the verifier represents all drawn shapes.

Use `--help` on the bundled scripts to discover supported flags before running;
record actual commands, configured angles/steps, tolerances, source/model hashes
and checked inputs. Read every failure and skip. Retain finite sample and numerical
precision limits rather than claim continuous mechanical safety.

## Measure and deliver honestly

Measure completed frames/operations and the actual renderer, viewport/DPR, workload
and work budget. Include startup, set/draw cost, DOM/style/layout and observer
cost where the claim needs them. Check intermediate captures and input takeover;
slower sampling or a noisy wall threshold cannot hide a defect. Missing GPU,
unsupported geometry or unavailable platform stays blocked. Deliver beta label,
supported envelope, actual sampled results, broken-control evidence and the
standalone fallback/limitations. Core SVG or one turning screenshot does not
qualify the whole beta workflow.
