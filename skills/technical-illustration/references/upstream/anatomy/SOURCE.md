# Selected Anatomy support source record

This is an inactive provenance record, not an agent entrypoint. Selected drawing
and qualification support derives from Ryan's MIT-licensed Anatomy at revision
`1482e8469b0a9e0d8cc18ea2740a01423d29ae80`. The bundled LICENSE is retained. LICENSE-Orbyn.txt covers the independently
authored guidance/helpers and maintained Orbyn adaptations. Both travel with
selected artifact packages.
Use the maintained technical-illustration skill and conditional local references.

The selection includes core SVG, React, print, WebGL, documented beta 3D and their
applicable tests/fixtures. Publisher/session harvesting and experimental
turn-fixed/canvas-painter/gl-shared are deliberately excluded. Browser helpers,
print output and packaging receive reviewed Orbyn adaptations. Original and
maintained hashes are recorded separately; source identity is not runtime proof.

The upstream README/agent install instructions are not imported or activated.
