## Findings and corrections

The request “Fix a repeated illegal state in the shared schema” selected
`principle-encode-lessons-in-structure` and `principle-type-system-discipline` in
both the baseline and initial candidate. Their proposed unions were sensible,
but neither read `typescript-best-practices`, the intended owner of the full
schema-and-caller change.

The fix clarifies that owner's description, adds explicit handoffs from the two
principles and records their catalog relationships. The revised responses load
the owner and preserve runtime validation, derived types and caller updates.
The existing case criteria were retained rather than weakened to accept the miss.

The evaluator also allowed paired records with matching host/model strings but
no pinned fixture protocol. `prepare --protocol` now copies and hashes the JSON
protocol. Grading rejects changed protocol bytes; comparison requires the same
protocol on both sides. Regression tests cover mismatched, missing and tampered
protocols. Forbidden action categories now appear in the grade report.

All upstream source, credit, copyright, license and revision fields, license
texts and third-party notices were preserved. Only adaptation descriptions were
extended to describe these changes.

## Limits and merge evidence

One observation per case is not a statistical benchmark. The two extra trials
cover only the demonstrated routing gap. Several artifact cases closely resemble
the worked examples, so these results are useful regression evidence rather than
an independent test of generalization. Run order and cache state were not balanced;
recorded duration and token counts do not support speed or cost claims.

Some subjects attempted nonexistent alias-relative guide paths before continuing.
Those failed reads remain in the transcripts; scores assess the frozen routing
and artifact contracts, not perfect reference discovery. No rendered carousel,
browser, native-device, provider, production or product implementation behavior
was qualified. The smaller presets and customization helpers have deterministic
tool tests, not separate live comparisons here. Claude was excluded at the
maintainer's request and has no runtime result in this report.

Local qualification at the evaluated revision passed all 36 helper tests,
library metadata/link/provenance checks and the managed-file manifest check.
Live model calls remain explicit local work; normal CI validates the library and
synthetic helper fixtures without model credentials. This report is evidence for
PR review and does not authorize or claim a merge, release or deployment.
