# Bulk CI and release evidence — 25 October 2026

The existing CI, investigation, testing and workflow owners now connect complete
failure collection, disk-backed analysis, supported correction and artifact-bound
release verification. The disposable exercise ran 54,000 actual fixture testcases;
separate capacity runs indexed up to one million normalized records, including
500,000 candidate failures. No Orbyn synchronization or REA upgrade occurred.

## Functional exercise

The local fixture has three suites × three environments × two instances: 18

source commits and runs baseline, broken and corrected source phases. Its artifact
is the tiny fixture's exact product-source bytes. Dependency availability and
stage promotion are controlled local simulations, not live services or VM instances.
The controller applies known corrections; this is not a live agent repair study.

The all-failing candidate contains 1,000 exact symptom groups. The compact summary
shows only 20 groups; streaming export verified **all 500,000 failures**, with
no top-list truncation, in a separate 7.85-second observation. Every exported row
was checked against its expected status/comparison. The full index retains
suite/environment/instance/variant/shard, attempt, run identity and report hash.

An additional generated JUnit report with 100,000 testcases converted in 0.51
seconds and retained its 99,000 passes and 1,000 failures. This qualifies that
bounded UTF-8 subset example, not every JUnit dialect or maximum file size.
Calibration also exercises a 1,000-slot matrix and rejects a removed required slot.

These are single local observations with bounded records/messages and one writer.
They do not establish arbitrary scale, peak concurrency, million-job orchestration
or portable throughput. Disk usage grows with retained history and the current
snapshot; bounded RAM does not remove storage requirements. Published byte/slot
ceilings are resource guards, not qualification of every maximum combination.

## Gaps found and corrected

The initial view-based lookup processed the 100,000-record mixed-failure case in
23.46 seconds. SQLite's query plan materialized the baseline and scanned it for
each candidate failure. The million-row attempt was stopped after prolonged
execution; its inputs, partial database and prior implementation remain preserved,
and it is not counted as a completed result. An indexed current-result snapshot
removes that repeated scan while retaining separate full attempt history. The
final capacity results above were rerun against the final helper hash.

Report validation also rejects duplicate identities/JSON fields, contradictory
JUnit counters, unsupported retry/outcome elements and partial malformed imports.
Missing, invalid or cancelled newest attempts cannot fall back to older green
results. The release verifier checks the actual artifact bytes as well as stage
repository, revision, configuration, current run, plan identity and freshness.
Neither grouping nor a local digest authenticates a provider or proves a cause.

## Validation and scope

All 142 Python tests, 65 bundled audit-validator fixture tests, library/assets/
manifest/discovery checks and `git diff --check` passed locally. The 13 new helper
tests cover failure inventories, retry preservation, missing/invalid reports,
selection/coverage, release faults, JUnit rejection, real fixture execution,
1,000-slot identity and managed-copy packaging. Normal CI discovers these checks
without model credentials, network dependencies or new deployment permissions.

All 54 canonical owners and inherited source/license notices remain. Nine
development case definitions bring the suite from 113 to 122, preserving every
previous case object and holdout. These definitions are not nine observed model
trials. No new live Codex/Claude evaluation was run in this milestone.

Raw fixtures, source/Git state, reports, successful/partial indexes, earlier
attempts and receipts remain in ignored local `output/bulk-ci-20261025/`; they are
not downloadable public artifacts. Provider adapters must independently establish
complete pagination and authentic metadata in a real consumer. Hosted approval,
ordered environment transitions, deployment/rollback and production health remain
outside this local evidence qualification. The tools assess evidence and never
deploy automatically. Orbyn promotion and the REA engine/source upgrade remain deferred.
