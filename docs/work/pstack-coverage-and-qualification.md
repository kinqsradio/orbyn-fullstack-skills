## Selected library improvements

The existing [architecture method](../../skills/architect/references/statecharts.md)
now includes a synthetic lossy-projection example with qualified action identities.
The existing [verification method](../../skills/tdd/references/formal-verification.md)
adds a per-property receipt example and conditional optional-compiler guidance.
Illustrative examples are separate from the actual tool observations below.
The existing [reproduction method](../../skills/how/references/reproduction.md)
adds a conditional shared-premise check after repeated ineffective fixes.
Four development evaluation definitions cover misleading projections, missing
property results, that premise check and an adjacent known-first-fix control.
All 247 prior case definitions, including holdouts, are preserved.
Case validation is static evidence; no new live agent trial was run for these cases.

No new skill, compiler vendoring, mandatory dependency, nesting change, model
selection or runtime default is introduced. Existing worktree, CI verification-map
and project verification owners remain responsible for their respective methods.
Executable compiler capability differs from written guidance; this comparison
makes no general engineering-performance ranking.
